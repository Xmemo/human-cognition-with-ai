# Weekly Search Protocol

## Objective

Detect **where the Human Cognition with AI research field changed this week**, not merely collect 12 papers.

## 1. Scan all nine radars

Every run must actively search all nine radars defined in [`research-map.md`](research-map.md). Coverage is mandatory; selection is not.

For each radar run two search families:

1. **Research evidence:** peer-reviewed papers, systematic reviews/meta-analyses, high-quality preprints, accepted/in-press research.
2. **Field signals:** research programs, lab/project updates, workshops, special issues, institutional reports, policy/guideline changes, substantive researcher talks or essays.

Start with the last 7 days. If a radar has too few meaningful results, expand to the last 30–90 days and label an item as `newly relevant` rather than pretending it was published this week.

## 2. Prioritize sources

Preferred order:

1. original journal / conference / arXiv page;
2. official university, research-lab, government, or international-organization page;
3. verified bibliographic record (including Consensus) used for discovery and metadata cross-checking;
4. high-quality secondary analysis only when the primary source cannot answer the relevant contextual question.

Do not use search-result snippets as evidence. Open/fetch the underlying record before inclusion.

## 3. Build one candidate pool

All qualifying candidates from all radars enter one pool. For each candidate record:

- title;
- authors / issuing institution;
- publication date;
- source / venue;
- item type;
- radar tag(s);
- main finding or claim;
- study design / sample where applicable;
- evidence grade;
- methodological caveat;
- canonical URL / DOI;
- whether discovered through Consensus.

## 4. Rank by value, not quota

Select up to **12 highest-value items** across the whole field. A radar may contribute several items or none.

Ranking factors:

- methodological strength;
- novelty of mechanism or finding;
- relevance to the 3×3 map;
- field-level importance;
- whether it changes or challenges the current working model;
- source quality;
- recency;
- redundancy with already-covered work.

Never pad a radar with weak material merely to achieve balance.

## 5. Priority frontier checks

Every run separately checks:

- Iyad Rahwan;
- Center for Humans and Machines, Max Planck Institute for Human Development;
- Machine Culture and close collaborators;
- machine behaviour;
- cumulative cultural evolution;
- human–AI groups / collective intelligence;
- AI metacognition / wisdom;
- social learning and cultural feedback.

A priority check guarantees search attention, **not guaranteed inclusion**.

## 6. Coverage record

Maintain an internal coverage record for all nine radars:

- `HIGH` — multiple meaningful new signals or one unusually important signal;
- `MEDIUM` — at least one useful but not field-changing signal;
- `LOW` — no item strong enough for the final shortlist.

The public brief may summarize this as `This Week's Field Signals`, but only when the labels are justified by observed evidence.

## 7. Freeze the evidence set

Before writing either public edition:

1. finalize source identity and citation metadata;
2. finalize evidence grade;
3. finalize caveat;
4. finalize item ordering;
5. freeze the same evidence set for both languages.

No second English research pass is allowed. This prevents bilingual drift.

## 8. Consensus synchronization

When Consensus is used:

- fetch the full Consensus record before citing it;
- deduplicate primarily by DOI, secondarily by normalized title;
- prefer DOI / publisher / arXiv as the public source link;
- retain the Consensus record URL in `references/consensus.md` for traceability;
- do not treat citation count as evidence strength;
- update bibliography files only for newly verified records.

## 9. Negative rules

Do not:

- convert correlation into causation;
- infer long-term cognitive decline from a one-session performance measure;
- infer learning from AI-assisted output quality alone;
- infer authorship from an AI detector score;
- describe a research program or institutional statement as empirical evidence;
- fabricate balance when a radar is quiet;
- use future-dated or unverifiable publications.
